# Tick Stock Panel 手机端（微信小程序）

原生微信小程序，局域网自用。手机通过 Wi-Fi 直连电脑上运行的 Tick Stock Panel 后端，后端代码不需要任何改动。

| 页面 | 功能 | 刷新方式 |
| --- | --- | --- |
| 自选 | 自选股现价、涨跌幅、成交额 | 交易时段每 5 秒轮询 `/api/watchlist/enriched`，其余时间下拉刷新 |
| 个股 | 日 K 线，叠加缠论的笔、线段、中枢和买卖点；列出近期买卖点 | 下拉刷新 |
| 选股 | 各策略今日命中数，点进去看命中股票；可一键运行全部策略 | 运行后每 3 秒轮询，直到后台算完 |
| 缠论 | 全市场缠论选股，按买卖点类型和信号新鲜度筛选 | 手动扫描（约 20 秒） |
| 告警 | 近 3 天的监控告警 | 交易时段每 10 秒轮询 |
| 设置 | 后端地址、连接测试、访问密码登录 | — |

小程序不支持 SSE，所以网页端通过 `/api/intraday/stream` 推送的内容，这里一律改为轮询。

## 第一次使用

1. **确认后端可以从局域网访问。** 后端默认监听 `0.0.0.0:3018`。Windows 防火墙需要放行 3018 端口的入站连接：
   打开「高级安全 Windows Defender 防火墙」，新建入站规则，选端口 TCP 3018，允许连接，配置文件只勾「专用」。
2. **查电脑的局域网 IP。** 命令行执行 `ipconfig`，记下 Wi-Fi 网卡的 IPv4 地址，例如 `192.168.1.10`。
3. **导入项目。** 打开微信开发者工具，选择「导入项目」，目录选本仓库的 `miniprogram/`。
   AppID 填你自己的小程序 AppID。用 `touristappid`（游客模式）只能在模拟器里看，不能真机调试。
4. **关闭域名校验。** 开发者工具里：详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
5. **填写后端地址。** 进入「设置」页，填 `http://192.168.1.10:3018`，点「保存并测试连接」。
   - 后端没设访问密码：在局域网内可以直接使用。
   - 后端设了访问密码：在设置页输入密码登录。会话保存在手机本地，有效期 30 天。

## 在手机上用

小程序直连的是局域网 IP，地址是 http 而不是 https，也没有在小程序后台登记过的合法域名。所以手机上必须走调试模式：

- **真机调试**：开发者工具点「真机调试」，用微信扫码。手机和电脑必须连同一个 Wi-Fi。
- **预览或体验版**：手机上打开小程序后，点右上角「…」→「开发调试」→「打开调试」，然后重启小程序。
  不打开调试的话，请求会被微信拦截。

以后如果想在不开调试模式的情况下使用，需要三样东西：一个备案过的域名、HTTPS 证书，以及在小程序后台把这个域名配置为 request 合法域名。
后端可以部署到云服务器，或者用内网穿透映射本机端口。

## 口径说明

- `change_pct` 是小数制（`0.05` 表示 5%），显示时乘以 100，与网页端 `fmtPct` 一致。
- 颜色按 A 股习惯：涨红、跌绿。
- 个股页的蜡烛和缠论叠加层都用前复权价（缠论接口传 `price_mode=qfq`）。
- 缠论结构按全市场最近 250 个交易日计算，与缠论选股用的是同一个窗口，所以选出来的票点进去看到的结构一致。
  图上只画最近约 200 根 K 线，更早的笔和中枢落在窗口外不画。
- 交易时段按北京时间判断（9:15–11:30、13:00–15:00，周一到周五），只用来决定要不要轮询，不判断节假日。

## 已知问题

- **单股缠论结构要 10 到 20 秒才返回。** 原因在后端：单股取历史数据时，要扫描 `kline_daily_enriched` 下全部约 8700 个日期分区。
  个股页会先画出 K 线，缠论叠加层算好后再补上。网页端缠论页也有同样的慢。
- **日 K 只取 290 个自然日。** 后端只缓存最近约 300 天，超出缓存的部分同样要扫全部分区，一次要 11 到 18 秒。
- **改了后端缠论代码后要重启后端。** 后端没有开自动重载，不重启的话，「结构一买 / 结构一卖」等新口径不会生效。

## 目录

```text
miniprogram/
  app.js / app.json / app.wxss   入口、tabBar、全局样式
  utils/config.js                后端地址与会话的本地存储
  utils/request.js               wx.request 封装（手动携带 tf_session cookie，处理 401 和网络错误）
  utils/api.js                   用到的后端接口清单
  utils/format.js                价格、涨跌幅、成交额、时间格式化
  utils/market.js                交易时段判断
  utils/chan.js                  缠论买卖点类型
  components/kchart/             Canvas 2D 日 K 图 + 缠论叠加层（支持拖动、点按）
  pages/                         watchlist / stock / screener / strategy / chan / alerts / settings
```
